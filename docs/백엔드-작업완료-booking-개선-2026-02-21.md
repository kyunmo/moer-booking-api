## 상세 변경 내용

### 1. [P0] 고객 프로필 403 오류 수정 (#3)

**원인 분석:**
- SecurityConfig에서 `/api/customer/**`가 `hasRole("CUSTOMER")`로 제한됨
- 기존 OWNER 계정이 고객 사이트에서 OAuth 로그인 시 OWNER 역할이 유지되어 403 발생
- CORS 설정이 `localhost:8080`, `localhost:5173`만 허용 (프로덕션 미지원)

**수정 내용:**

| 파일 | 변경 |
|------|------|
| `SecurityConfig.java` | `.hasRole("CUSTOMER")` → `.authenticated()` 로 변경 |
| `SecurityConfig.java` | CORS 허용 출처를 환경변수 `CORS_ALLOWED_ORIGINS`로 변경 |
| `application.yml` | `app.cors.allowed-origins` 설정 추가 |

**프론트엔드 영향:**
- 403 오류 해소됨. 기존 API 호출 방식 변경 없음
- **프로덕션 배포 시** 환경변수 설정 필요:
  ```
  CORS_ALLOWED_ORIGINS=https://yemo.kr,https://api.yemo.kr,http://localhost:5173
  ```

### 6. [P1] 네이버/구글 고객 OAuth 확인 (#2)

**결론: 이미 완전히 구현되어 있습니다.**

**사용 가능한 고객 OAuth 엔드포인트:**

| 제공자 | URL |
|--------|-----|
| 카카오 | `GET /oauth2/authorize/kakao?loginType=customer` |
| 네이버 | `GET /oauth2/authorize/naver?loginType=customer` |
| 구글 | `GET /oauth2/authorize/google?loginType=customer` |

**콜백 응답 (모든 제공자 동일):**
```
{customerRedirectUri}?accessToken=...&refreshToken=...&loginType=customer&isNewUser=true
```

**동작 흐름:**
1. 프론트에서 `/oauth2/authorize/naver?loginType=customer` 호출
2. `CustomAuthorizationRequestResolver`가 `moer_login_type=customer` 쿠키 설정
3. 네이버/구글 OAuth 인증 진행
4. `CustomOAuth2UserService`가 쿠키 읽어 CUSTOMER 역할로 사용자 생성
5. `OAuth2AuthenticationSuccessHandler`가 `customerRedirectUri`로 리다이렉트

**프론트엔드 필요 작업:**
- 네이버/구글 로그인 버튼에 위 URL로 리다이렉트 연결
- `isNewUser=true`인 경우 프로필 완성 화면으로 이동

**프로덕션 환경변수:**
```
OAUTH2_CUSTOMER_REDIRECT_URI=https://yemo.kr/oauth2-redirect
```
