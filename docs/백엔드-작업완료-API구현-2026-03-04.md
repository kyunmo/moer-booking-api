## 주요 구현 결정

### 이미지 업로드
- 기존 `FileStorageService` (로컬 파일 시스템) 활용
- URL 형식: `/uploads/services/{serviceId}/{uuid}.{ext}`
- 썸네일 자동 생성은 미구현 (향후 추가 가능)

### 리뷰 이미지
- 방안 A 채택: multipart 동시 업로드
- 기존 JSON body 엔드포인트 유지 (하위 호환)
- Content-Type으로 자동 분기 (multipart vs JSON)

### 회원가입
- `selectedPlan` 필드 유지 (하위 호환), 값 무시
- 항상 `SubscriptionPlan.FREE` + `SubscriptionStatus.TRIAL` + 30일

### SSE 이벤트
- HEARTBEAT: 30초 간격 자동 전송
- RESERVATION_CREATED/CANCELLED: 예약 생성/취소 시 매장 owner에게
- REVIEW_CREATED: 리뷰 생성 시 매장 owner에게
- `sendEventToBusinessOwner()` 구현 완료

### 카카오 알림톡
- 설정 저장만 구현 (실제 카카오 API 연동은 미구현)
- `business_settings` JSONB에 트리거 설정 저장

### 고객 CRM
- 태그: `customers.tags` VARCHAR에 콤마 구분 문자열
- CSV: UTF-8 BOM 포함 (엑셀 한글 지원)
- 병합: 전화번호 기반 중복 감지, 트랜잭션 내 예약/메모 이관

### 도움말
- 카테고리 Enum: RESERVATION, STAFF, SERVICE, PAYMENT, STATISTICS
- SuperAdmin CRUD + Public 조회 분리
